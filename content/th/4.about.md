นักพัฒนา Full-Stack สัญชาติไทย

พัฒนาเว็บแอปพลิเคชันครบวงจร — ตั้งแต่หน้าบ้านด้วย React, Vue และ Next.js ไปจนถึงระบบหลังบ้านที่แข็งแรงด้วย Laravel, FastAPI และ Node.js รวมถึงย้ายระบบเดิม (C#/VB.NET Webforms) และออกแบบฐานข้อมูล

เน้นส่งมอบระบบที่เสถียร ดูแลรักษาง่าย และแก้ปัญหาจริง — ไม่ว่าจะเป็นเครื่องมือบริหารจัดการธุรกิจ REST API หรือสร้างผลิตภัณฑ์ใหม่จากศูนย์
